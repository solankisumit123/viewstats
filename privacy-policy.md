# ViewStats Privacy Policy

ViewStats Desktop is a Windows desktop application that helps users browse YouTube content and view analytics-related information.

## Information we collect

- YouTube public metadata and channel/video information requested by the user through the app.
- App usage events needed for troubleshooting, crash diagnostics, and product improvement.
- Local settings required for app operation, such as preferences and cache files.

## How information is used

- To provide the app’s core browsing and analytics experience.
- To improve app stability, update delivery, and user support.
- To handle requests to YouTube public content endpoints as needed by the user.

## Data sharing

We do not sell user personal data. We may share limited data with trusted service providers only when necessary to run the app, maintain service availability, or meet legal requirements.

## User control

Users may delete local app data and cache files from their device at any time. If the app uses external services, users should review those providers’ own privacy terms.
