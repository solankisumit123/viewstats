# ViewStats Desktop

ViewStats Desktop is a Windows desktop application for discovering YouTube channels, browsing trending content, and reviewing analytics-focused information in a polished desktop experience.

## What the app does

- Browse YouTube content from a desktop interface
- Review channel and video metadata quickly
- Provide a stable Electron-based installer experience for Windows users
- Support update checks and a lightweight local desktop workflow

## Build and package

```bash
npm install
npm run build
npm run electron:build
```

## Publish-ready notes

- The installer should be submitted with a clear app description
- A public privacy policy URL should be available in the store listing
- The app should use a clean icon, proper title, and professional metadata
- The published version should match the same package identifier on re-submission
